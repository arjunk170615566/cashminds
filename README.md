# 💰 CashMinds

CashMinds is an **AI-powered Personal Finance Management System** built using the **MERN Stack**. It helps users manage their finances efficiently by tracking income, expenses, and transactions while simplifying expense entry through AI-based bill scanning.

## 🚀 Features

### 🤖 AI Bill Scanner

Upload a receipt or bill, and the AI automatically extracts:

* Merchant Name
* Transaction Amount
* Transaction Date
* Expense Category

The extracted information is used to automatically create a transaction, reducing manual data entry.

### 💳 Transaction Management

* Add income and expenses
* Edit existing transactions
* Delete transactions
* Filter and organize financial records

### 📊 Dashboard & Analytics

* Financial summary
* Income vs Expense overview
* Recent transactions
* Spending insights

### 🔐 Secure Authentication

* User Registration
* Secure Login
* JWT Authentication
* Protected API Routes

### 📱 Responsive Design

Works smoothly on desktops, tablets, and mobile devices.

# ⚡ Installation

```bash
git clone https://github.com/arjunk170615566/cashminds.git

cd cashminds

# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

Run Backend

```bash
npm run dev
```

Run Frontend

```bash
npm run dev
```
